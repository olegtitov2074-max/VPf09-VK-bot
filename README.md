# VPi04 VK AI Bot

Учебный проект VPi04: интеллектуальный AI-бот для сообщества ВКонтакте.

Проект создан как отдельная рабочая копия проекта VPf09-VK-bot. В этой версии сохранены интерфейс VK, многодиалоговый режим, JSON-память и режимы общения, а AI-интеграция переведена на OpenAI-совместимый API ProxyAPI с моделью `gpt-4.1-mini`.

## Возможности

- Приём сообщений сообщества VK через Bots Long Poll API
- Главное меню и VK-клавиатуры
- Создание и переключение независимых диалогов
- Краткосрочная память: история активного диалога передаётся AI-модели как контекст
- Хранение состояния диалогов в JSON
- Режимы общения:
  - Обычный помощник
  - Программист
  - Преподаватель
  - Бизнес-консультант
  - Дружелюбный собеседник
- Асинхронная обработка сообщений
- Отображение статуса обработки сообщения
- Обработка ошибок AI API без остановки VK-бота
- Конфигурация через `.env` без публикации секретов

## Требования

- Python 3.11+
- Сообщество VK с включёнными сообщениями и Bots Long Poll API
- Токен доступа сообщества VK
- API-ключ ProxyAPI
- Доступ к модели `gpt-4.1-mini`

## Установка

Клонируйте репозиторий:

```powershell
git clone [https://github.com/](https://github.com/)<YOUR_GITHUB_LOGIN>/VPi04-VK-AI-bot.git
cd VPi04-VK-AI-bot
```

Создайте виртуальное окружение:

```powershell
python -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
pip install -r requirements.txt
```

## Конфигурация

Создайте файл `.env` на основе `.env.example`:

```powershell
Copy-Item .env.example .env
```

Заполните обязательные переменные. Названия некоторых переменных могут зависеть от конфигурации VK-слоя проекта; используйте шаблон `.env.example` как основной источник.

Для AI-интеграции укажите:

```env
AI_API_KEY=ваш_ключ_ProxyAPI
AI_BASE_URL=[https://api.proxyapi.ru/openai/v1](https://api.proxyapi.ru/openai/v1)
AI_MODEL=gpt-4.1-mini
```

Также укажите токен сообщества VK в переменной, которую ожидает `.env.example`.

Никогда не добавляйте `.env` в Git: в нём находятся секреты.

## Настройка сообщества VK

1. Создайте или используйте сообщество VK.
2. Включите сообщения сообщества.
3. Включите возможности ботов и кнопку «Начать».
4. Перейдите в:
   ```text
   Управление → Дополнительно → Работа с API
   ```
5. Создайте ключ доступа сообщества с правами на сообщения.
6. Включите Bots Long Poll API.
7. В разделе «Типы событий» включите события входящих сообщений.

## Запуск

Активируйте окружение и выполните:

```powershell
python run.py
```

После успешного запуска бот начинает получать входящие события из сообщества через Long Poll.

## Демонстрация

Для проверки:

1. Откройте сообщения сообщества VK.
2. Нажмите «Начать» или отправьте `/start`.
3. Откройте главное меню.
4. Создайте или выберите диалог.
5. Выберите режим общения, например «Бизнес-консультант».
6. Отправьте вопрос и затем уточняющий вопрос в том же диалоге.

Бот должен учитывать тему первого вопроса при ответе на уточнение, так как история текущего диалога передаётся модели как контекст.

## Миграция AI-интеграции

Исходная версия использовала Gemini через Google GenAI SDK и ProxyAPI. При запуске возникла ошибка авторизации `401 Invalid API Key`.

В VPi04 AI-слой был точечно переведён на OpenAI-совместимый API ProxyAPI:

- `Google GenAI SDK` заменён на `AsyncOpenAI`;
- используется `AI_API_KEY`, `AI_BASE_URL` и `AI_MODEL`;
- выбранная модель: `gpt-4.1-mini`;
- VK Long Poll, JSON-память, меню, обработчики и клавиатуры не изменялись.

Проверка после миграции: бот успешно получает ответы от AI через ProxyAPI.

## Выбор AI-инструмента

Для сопровождения и развития проекта выбран OpenCode:

- проект многомодульный, но пока не требует анализа огромной кодовой базы;
- нужна работа с разными типами задач: Python, async, VKBottle, JSON, промпты, документация и отладка;
- важно переключать модели и контролировать расходы;
- OpenCode позволяет выполнять точечные изменения в одной среде.

Cloud Code был бы предпочтителен для глубокого анализа и рефакторинга крупного проекта. Codex CLI был бы удобен для максимально быстрого создания отдельного нового прототипа.

## Безопасность

- Токен сообщества VK и ключ ProxyAPI не публикуются.
- SSL-проверка не отключается.
